# T100 主动一线通：USB 网卡模块复用版（Rev A）

> **这版优先采用低成本拼装，不自研 RTL8153B 电路。** 买现成 USB 3.0 千兆网卡模块，保留它完整的 USB 网卡 PCB；另加 5V→11V 升压模块和一块极简 RJ45 供电注入小板。当前文档是可搭建的原型方案，不是经过实测的量产设计。

## 1. 目标形态

- RDK X5 / Orange Pi 5B：优先插 USB 3.0 Type-A Host。
- 普通电脑：有 USB-A 就直插；只有 USB-C 时用 USB-C 转 USB-A 3.0 转接头。
- 主机只枚举一张 USB Ethernet 网卡，不改 USB 协议、不写驱动。
- USB 网卡 RJ45 后面接一块小型被动供电注入板。
- 注入板输出一根 Cat5e 线，另一端为 T100 专用 24Pin Type-C。
- T100 目标工作点 11.0V；上游记录实测约 0.345A（约 3.8W）。这不是已知完整额定电压范围。

## 2. 最简系统结构

~~~text
RDK X5 / Orange Pi 5B / PC
          |
          | USB 3.0 cable
          v
+--------------------------------+
| 现成 USB 3.0 -> Gigabit NIC     |
| RTL8153 / RTL8153B 模块         |
|                                |
| 保留原 PCB、USB 口、PHY、磁性器件 |
+--------------------------------+
          |
          | RJ45（标准网口）
          v
+--------------------------------+
| 极简 RJ45 供电注入板            |
|                                |
| IN:  1,2,3,6 -> OUT: 1,2,3,6    |
| IN:  4,5,7,8 -> 不连接           |
| OUT: 4,5 -> +11V                |
| OUT: 7,8 -> GND                 |
+--------------------------------+
          |
          | Cat5e T568B 四对线
          v
T100 定制 Type-C A 面
  100BASE-TX + 11V
~~~

**重点：不要把 11V 直接注入 USB 网卡模块自身的 RJ45 插座 4/5、7/8。** 很多 RTL8153 千兆网卡使用四对磁性器件，备用线对的中心抽头、Bob-Smith 终端或 ESD 结构不一定为被动供电设计。PoE 设计需要专门处理磁性器件中心抽头和 Bob-Smith 网络；普通网卡不能仅凭“100M 只用两对”就认定备用两对可以随便加电。Microchip 的磁性器件指南说明了 PoE 共模供电与中心抽头/终端网络的关系。

本方案在网卡与雷达之间增加一个**输入侧备用线对完全断开的注入板**，让 11V 不进入 USB 网卡的 RJ45 磁性器件。

## 3. 现成 USB 网卡怎么选

购买完整的 USB 3.0 千兆网卡模块，不要买裸 RTL8153B 芯片。

优先条件：
- 明确使用 RTL8153 / RTL8153B；
- USB 3.0 / USB 3.2 Gen 1，不能是 USB 2.0 版本；
- 有独立 USB-A 插头或短线，方便拆壳和取 5V/GND；
- 有独立 RJ45 插座；
- PCB 不要灌胶，最好能拆壳；
- 优先购买能看到 PCB 正反面照片、芯片丝印和 RJ45 磁性器件布局的版本。

买回来先不要焊接：
1. 接电脑，执行 `lsusb`，确认枚举为 Realtek USB GbE（常见 VID:PID 为 `0bda:8153`，具体版本可能不同）。
2. 执行 `ip link` 或 `ethtool -i <网卡名>`，确认 Linux 使用内核 `r8152` 驱动。
3. 接普通路由器，确认 USB 侧为 SuperSpeed，Ethernet 可协商 1000M。
4. 接 T100 后再确认能协商 100M Full Duplex，并持续收 UDP 60001/60003。

RTL8153B 的 USB/PHY/时钟/磁性器件电路相对复杂；复用完整成品 PCB 的价值就在于不用自己处理这些高速电路。

## 4. 5V 取电与升压

### 4.1 取电方式

最简单的原型：打开 USB 网卡外壳，在 USB 插座/插头 PCB 焊盘处引出：
- `VBUS_5V`：USB 5V；
- `GND`：USB 地。

这两根线只给升压模块输入供电；不要改动 USB2 D+/D− 或 USB3 SuperSpeed 差分线。

更干净的做法是用 USB 3.0 直通 breakout 板取 5V/GND，但必须买真正保留 SuperSpeed 四组差分线的 USB 3.0 breakout，普通 USB2 小板会让网卡降速或无法枚举。

### 4.2 升压模块

先买现成可调升压模块，不必第一版自画 TPS61088：

| 项目 | 原型目标 |
|---|---|
| 输入 | USB VBUS 5V |
| 输出 | 11.0V（先用万用表调准） |
| 连续输出能力 | 至少 11V / 0.5A |
| 输入能力 | 建议能承受 5V / 1.5A 以上 |
| 保护 | 输入短路/过流、输出限流、过温 |
| 启动 | 有软启动更好 |

不要默认 MT3608 小板能长期承担这个负载。模块标注的“2A/3A”常常是开关峰值或理想条件值，不等于 5V 输入、11V 输出时可连续输出 0.5A。

初次测试用实验电源给升压板供 5V，电子负载检查 11V 输出和温升；确认稳定后再接 T100。T100 的启动峰值电流尚未测量，输出限流值应根据实测设置，不要凭 0.345A 稳态值直接把限流设成 0.35A。

### 4.3 USB 口供电预算是这个方案最大的风险

T100 稳态输出功率约为：

`11V × 0.345A = 3.80W`

按升压效率 90% 估算，仅雷达就需要：

`3.80W / (5V × 0.90) ≈ 0.84A`

还要加 USB 网卡本身的耗电和启动峰值。因此总输入可能接近或超过 1A。

- 标准 USB 3.0 Type-A 供电预算通常是 900mA，可能不够。
- RDK X5 的 USB 3.0 Type-A 端口有约 1A 的供电规格，仍然非常接近边界。
- Orange Pi 5B 要实测具体 USB Host 端口限流，不能把整板 5V/4A 输入能力当成 USB 单口能力。
- USB 2.0 Host 不适合此方案。
- 只有当主机 USB 口确实能稳定提供所需电流时，才可实现真正的单 USB 线供电。

建议先用 USB 功率计记录启动和稳态电流。如果主机口掉压或限流，最简单的兜底是给升压模块单独接 5V 大电流电源；这会牺牲单线供电，但数据仍然只走一根网线。不要通过屏蔽 USB 限流或短接识别脚强行取电。

## 5. RJ45 注入板：只需要两个 RJ45 插座和直连焊盘

注入板不需要 PHY、不需要变压器、不需要 USB 芯片。它只负责把数据四根线直通，并把备用四根线接到电源。

建议用两个**无磁性器件的普通 RJ45 母座**：
- J1：连接 USB 网卡的 RJ45；
- J2：连接通往 T100 的 Cat5e 线缆。

连接表：

| J1（网卡侧） | J2（雷达线侧） | 说明 |
|---:|---:|---|
| 1 | 1 | ETH1 |
| 2 | 2 | ETH1 |
| 3 | 3 | ETH2 |
| 6 | 6 | ETH2 |
| 4 | 不连接 | 网卡侧备用线对隔离 |
| 5 | 不连接 | 网卡侧备用线对隔离 |
| 7 | 不连接 | 网卡侧备用线对隔离 |
| 8 | 不连接 | 网卡侧备用线对隔离 |

J2 的供电连接：
- J2-4 与 J2-5 并联接升压输出 +11V；
- J2-7 与 J2-8 并联接升压输出 GND；
- 电源入口预留保险/限流和输出电容；
- 电源正负极不要接到 J1 的任何针脚。

这样 J1 的 4/5/7/8 与 USB 网卡磁性器件完全断开，11V 只出现在 J2 的雷达侧备用线对上。

### 原型最省事的做法

可以先买两个 RJ45 8P8C 直通 breakout 小板，用短线连接 J1/J2 的 1、2、3、6；J1 的 4、5、7、8 不焊；J2 的 4/5 接 +11V、7/8 接 GND。确认连通关系后再画小 PCB。

**不要买带 PoE 供电功能、内部接线不明的 RJ45 耦合器来替代这块注入板。** 先用万用表确认输入侧备用针脚完全悬空。

## 6. 网线到 T100 的针脚定义

使用 T568B、24AWG 纯铜 Cat5e。T100 端只按上游工程确认的 A 面接线：

| RJ45（J2） | T568B 颜色 | 功能 | T100 Type-C A 面 |
|---:|---|---|---|
| 1 | 橙白 | ETH1 | A10 |
| 2 | 橙 | ETH1 | A11 |
| 3 | 绿白 | ETH2 | A2 |
| 6 | 绿 | ETH2 | A3 |
| 4 | 蓝 | +11V | A6 |
| 5 | 蓝白 | +11V | A7 |
| 7 | 棕白 | GND | A1 |
| 8 | 棕 | GND | A12 |

A4、A8、A5、A9 全部不接。只接 T100 Type-C A 面，不要把 A/B 两面重复短接。

这不是 IEEE PoE。J2 是**专用 11V T100 口**，不能插普通电脑、交换机、路由器或标准 PoE 设备。建议在 J2 周围印上醒目的 `T100 11V ONLY`。

## 7. 原型接线总图

~~~text
USB 3.0 Host
   |
   +---- USB 数据 + 5V ---------------- USB RTL8153B 网卡
   |                                      |
   |                                      +---- RJ45
   |                                             |
   |                                    J1 供电隔离注入板
   |                                      | 1,2,3,6 数据直通
   |                                      | 4,5,7,8 输入侧 NC
   |                                      |
   |                              J2 4,5 = +11V
   |                              J2 7,8 = GND
   |                                      |
   |                                      +---- Cat5e ---- T100
   |
   +---- VBUS/GND 分支 ---- 5V->11V Boost ----+
~~~

## 8. 首次上电和验收顺序

1. **只测 USB 网卡**：不接升压，不接 T100；确认 USB3 枚举、Linux r8152 驱动和普通网络通信。
2. **单测升压**：实验电源 5V 输入，输出调到 11.0V；测空载、0.35A 负载和温升。
3. **单测注入板**：J1 接网卡但不接 T100；J2 输出测 11V 极性；万用表确认 J1-4/5/7/8 与 J2-4/5/7/8 不通。
4. **验证数据直通**：先不接 11V，只用网线确认 100BASE-TX 链路。
5. **限流上电 T100**：先用台式电源确认 11V 启动电流和稳态电流，再接升压模块。
6. **验证长时间收包**：连续收 UDP 60001 和 60003，检查丢包、网卡掉线、升压温升和主机 USB VBUS 电压。
7. **最后测线长**：先 1–3m，再 5m；检查雷达端电压是否仍在稳定工作范围。

## 9. 后续优化

原型验证成功后，才把升压模块、输入/输出保护和 RJ45 注入板整合到一块小 PCB。USB 网卡 PCB 继续复用，不要重画 RTL8153B。

如果未来想把 USB-C 主机口也做成直连版本，可另做 USB-C UFP 输入板；但对 RDK X5 / Orange Pi 5B，第一版用 USB 3.0 Type-A Host 最简单。
